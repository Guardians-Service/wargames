📌 문제 제목
JWT Lab - Medium

🎯 문제 설명
이 서비스는 로그인 시 HS256 알고리즘으로 서명된 JWT를 발급합니다.
발급되는 토큰은 항상 role: user 클레임을 가지며, 정상적인 로그인 절차로는 role: admin 토큰을 받을 방법이 없습니다.

/admin 엔드포인트는 role: admin 클레임을 가진 유효한 토큰을 제시해야만 flag를 반환합니다.
서명에 사용된 비밀키(secret)를 알아낼 수 있다면, 원하는 클레임을 담은 토큰을 직접 만들어낼 수 있습니다.

🧠 난이도
중 (Medium)

💡 힌트
서명 키는 짧고 흔한 문자열입니다. 발급받은 토큰을 jwt_tool이나 hashcat 같은 도구, 혹은 간단한 파이썬 스크립트로 워드리스트/브루트포스 크래킹 해보세요.
비밀키를 알아냈다면 PyJWT 등으로 role: admin 클레임을 가진 토큰을 직접 서명해서 /admin에 제출하세요.
